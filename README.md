# Mi Biblioteca

La pila de libros de mi cómoda, en 3D. Toma un libro para ver su portada, su contraportada, de qué trata, sus premios y mi reseña.

- Pasa el cursor (o toca) un libro y haz clic para tomarlo; clic sobre él para darlo vuelta.
- Teclado: ← → para recorrer la pila, Enter para abrir, Esc para devolverlo.
- Las calificaciones y comentarios se guardan en el navegador. Para que todos los vean, exporta tus reseñas y sube el archivo `resenas.json` a este repositorio.
